🤖 Acerca de TalentIA

TalentIA es un agente autónomo diseñado para apoyar el proceso de reclutamiento y selección de personal mediante el análisis inteligente de currículums vitae.

🎯 Objetivo

Automatizar la evaluación de candidatos, identificar los perfiles más adecuados para una vacante y generar información útil para la toma de decisiones.

⚙️ ¿Por qué es un agente autónomo?

👁️ Percibe

Recibe CVs, datos de candidatos y requisitos de vacantes.

🧠 Razona

Analiza habilidades, experiencia y compatibilidad entre candidatos y vacantes.

🎯 Decide

Determina qué candidatos poseen mejor perfil para una determinada vacante.

⚡ Actúa

Genera rankings, reportes y apoyo para la comunicación con candidatos.

🛠 Tecnologías Utilizadas

  • Python
  • Flask
  • SQLite
  • PyPDF2
  • python-docx
  • Pandas
  • OpenPyXL
  • FPDF
  • Bootstrap 5

👥 Roles del Sistema

  • Candidato: registra información y adjunta su CV.
  • Administrador: gestiona vacantes, candidatos y resultados.
